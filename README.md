# Fiona Wu — Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. No build step or package installation is needed.

## Preview

Open `index.html` in a modern browser. Google Fonts are used when the browser has internet access; system serif and sans-serif fonts are the fallback.

## Assets to add

The first draft intentionally uses labeled placeholders because the project images, poems, and research PDF were not included with the brief.

- `assets/filmmaking/` — Boxes editing/BTS images; production design finals and process images; System Error, Choices, and City Soul stills.
- `assets/multimedia/` — In Transit full installation hero (the third supplied view), detail views (the first two), and the Whispers before Vanishing research PDF.
- `assets/content/` — Xiaohongshu covers and the Library as Community Space reel cover.
- `assets/photography/` — 23 photographs across Tides of Blue (5), Ran in Youth (5), Stay in Color (7), and People Who Wait (6), plus the poem/text for each series.

The supplied video, RedNote, and Instagram links are already connected. Existing project descriptions should be added from the original portfolio when its copy is available; they are not invented here.

## Updating content

Project titles, links, descriptions, and gallery slots live in `index.html`. Shared visual styling lives in `styles.css`; interactions live in `script.js`. Replace each labeled placeholder with an image element pointing to its file under `assets/` when assets are ready. Keep the image alt text descriptive.

The homepage/about hero uses `assets/homepage/fiona-about-background.jpg` as its full-width background. The smaller taped portrait frame remains a separate labeled slot for another image. Small hand-drawn SVG icons and hover-responsive doodles are part of the page itself.

Current style direction: lavender and sage with vintage rose accents, handwritten display labels, and all four photography series open with their galleries visible on page load.
